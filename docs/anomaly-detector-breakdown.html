① – ③ Ingest & validate

The client (a CICFlowMeter sidecar, a CSV upload, or the dashboard's manual-scoring form) POSTs one or more flows. FastAPI's async ingress passes the JSON to Pydantic v2, which enforces the FlowRecord schema and rejects malformed payloads with a 422 before any model code runs.

④ Feature transform

The persisted ColumnTransformer (median imputation + RobustScaler + OneHotEncoder) maps the 20-feature CIC-flow record into the exact vector space the model was trained on. Bundling pipeline and model in a single joblib artefact guarantees train/serve parity — one of the most common false-positive sources in the literature.

⑤ – ⑥ Classify & bucket

Gradient Boosting emits an 8-class verdict (BENIGN or one of seven attack categories) plus a probability vector. The severity bucketer collapses that into info → critical, optionally gated by an operator-supplied threshold so analysts can dial sensitivity per investigation without retraining.

⑦ – ⑨ Persist, respond, observe

Every classification — benign or attack — is appended to the SQLite audit store for forensic replay, then the JSON verdict returns to the client. In parallel, the Streamlit dashboard polls /metrics and /alerts every few seconds to refresh the analyst view.

Animation is purely illustrative — dot colour, throughput and attack mix are driven by the controls above. The real artefact lives at github.com/Guts1313/AnomalyDetector.
